# Demae — Official Artist Website

Official artist website for **Demae**, built from the approved master October artist website template.

## Features
- **Hero Background & Visuals**: High-performance responsive hero video with sharp 1080p poster frame (`hero-poster.jpg`) and automated phone-upload optimization via GitHub Actions.
- **Discography & StreamModal**: Direct multi-platform streaming links (Spotify, Apple Music, YouTube Music, Deezer, Amazon Music, Tidal, Bandcamp, SoundCloud, iTunes) for 5 featured releases:
  - *Steppers (Live Session)* (Single, Aug 26, 2026)
  - *Don't Play The Fool (Live Session)* (Single, Aug 5, 2026)
  - *Deep Dive* (Album, Nov 7, 2025)
  - *Deliver Me* (EP, Sep 4, 2024)
  - *Life Works Out... Usually* (Album, Sep 18, 2020)
- **Videos Section & Featured Visuals**: Official live sessions and music videos:
  - *Demae - Steppers (Live Session)*
  - *Demae - Don't Play The Fool (Live Session)*
  - *Demae - Thank You (feat. Yukimi)*
  - *Demae - Don't Play The Fool*
- **Official Merchandise Store**: Integrated official store linking directly to [demaemerch.com](https://demaemerch.com).
- **Socials & Streaming Bar**: Verified icons and direct links for Spotify, Apple Music, YouTube, Instagram, TikTok, Bandcamp, and SoundCloud.

## Development & Deployment
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Type check
npm run lint

# Build for production
npm run build

# Deploy to Cloudflare
npx wrangler deploy
```
